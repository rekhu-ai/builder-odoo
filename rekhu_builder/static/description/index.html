Rekhu Builder

The AI agent for Odoo developers. It reads your database as it runs, designs your models with you, and builds, tests and upgrades your custom modules, on a git branch of its own. You work in a chat; every run can be undone.

Odoo 17, 18, 19 and 20 · Community and Enterprise

Describe it, and it is built

"A module for renting out equipment: equipment with a serial number, a category, a daily price and a state; rentals with dates, and the days and total computed from them." It shows the design in a short table, then writes the module the Odoo way:

  • Models with their fields and relations, computed fields and constraints.
  • List, form and search views, an action and a menu, and access rights.
  • A test for each model. Then it installs the module and runs the tests.
  • Every file is checked as it is written: Python, XML, the manifest, the access rights.

It knows the database you run

Before it changes anything, it reads what is there:

  • The installed modules and where they come from: Odoo, Enterprise, the store or your own.
  • Every model with its fields, and the module that added each field.
  • The relations between models, as a diagram.
  • How a field is used in the data before you redesign it: how many records have it set, and its commonest values.
  • Views and what inherits them, menus, access rights and record rules, scheduled actions that fail, and the log.

Personal fields are masked unless asked for by name. SQL runs read only.

  • It writes only in your custom addons folders, never in Odoo's own modules or Enterprise.
  • With git, every change goes on a branch rekhu/<run>, one commit each, for you to merge. Without git, every file is backed up first.
  • Undo puts a run back: files restored, a module it installed uninstalled, the branch you started from checked out.
  • Tests run in a separate Odoo process on a database of their own, never on yours.
  • Every call from Rekhu is signed with this database's own secret and can be used once.

Works where you develop

  • A laptop, Docker or a server behind a firewall: run the listener, odoo rekhu_listen -d mydb. It connects out, so nothing has to be opened inbound. If a change stops the database from loading, the listener keeps a repair mode for the files, git, checks, upgrade and undo.
  • A server with a public https address: Rekhu calls it directly.
  • Odoo Online does not take custom modules, so it can't be used there.

It also sets up Rekhu Assistant for the people who work in Odoo: where it works, its help topics, and actions of your own.

Get started

  1. Create a Rekhu account: it starts with $10 credit, no card needed. Add a project of the type Odoo. Under Connection, make a key for Rekhu Builder.

  4. On a laptop or in Docker, start the listener. Then talk to the builder in your project chat.
